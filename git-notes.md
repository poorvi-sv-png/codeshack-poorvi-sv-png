💜 Git Commands Handbook

1. git init
Initializes a new Git repository.
Example: git init

2. git clone
Copies a remote repository to your computer.
Example: git clone https://github.com/USERNAME/REPO.git

3. git status
Shows the current state of your files.
Example: git status

4. git add
Stages changes for a commit.
Example: git add README.md

5. git commit
Saves staged changes in Git history.
Example: git commit -m "Add notes"

6. git log
Displays commit history.
Example: git log --oneline

7. git diff
Shows unstaged changes.
Example: git diff

8. git push
Uploads local commits to GitHub.
Example: git push -u origin main

9. git pull
Fetches and integrates remote changes.
Example: git pull origin main

10. git fetch
Downloads remote updates without integrating them.
Example: git fetch origin

11. git branch
Lists or creates branches.
Example: git branch feature-branch

12. git checkout
Switches branches.
Example: git checkout feature-branch

13. git merge
Integrates another branch into the current branch.
Example: git merge feature-branch

14. git remote -v
Displays remote repository URLs.
Example: git remote -v

15. git show
Displays details about a commit.
Example: git show HEAD

---Feature Branch Workflow---

A feature branch lets developers work on new changes without directly modifying the main branch.

Example commands:

1. git branch feature-branch: Creates a branch.
2. git checkout feature-branch: Switches to the branch.
3. git add . : Stages changes.
4. git commit -m "Add feature": Records changes.
5. git push -u origin feature-branch: Pushes the branch to GitHub.
